# Documentation Guide

This directory contains concise, durable context for people and AI agents. Read only the documents relevant to the current task, then verify important details against the repository.

- `project-context.md` — What is this project and why does it exist?
- `architecture.md` — How is the project organized?
- `decisions.md` — Why were important decisions made?
- `workflow.md` — How should work be performed?
- `maintenance.md` — What has happened, what is happening, and what remains?

Keep project-specific knowledge in its appropriate document. Use maintenance for current and historical handoff context, then promote information that becomes durable knowledge.
